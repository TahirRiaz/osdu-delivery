# OSDU Delivery for VS Code

Develop OSDU Delivery pipelines in the editor: every YAML document understood, mappings checked against their templates
as you type, the estate and its runs at hand, and the assistant built in. Powered by SQLFlow.

Sign in through your browser with your Microsoft account, open a repository, and start from the Document and Repository
views. [The guide](https://github.com/TahirRiaz/osdu-delivery/blob/main/osdu/docs/reference/guides/vscode.md) has the rest.
